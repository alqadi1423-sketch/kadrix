# الإعدادات

يقرأ Kadrix إعداداته من متغيرات البيئة. مع Docker ضعها في الملف `.env`، وبدونه في ملف بيئة الخدمة.

## المطلوبة

| المتغير | المعنى |
|---|---|
| `DATABASE_URL` | اتصال PostgreSQL، مثل `postgres://kadrix:password@localhost:5432/kadrix` |
| `AUTH_SECRET` | 32 حرفًا عشوائيًا على الأقل. يوقّع الجلسات ويشفّر أسرار الخطافات والتكاملات. تغييره يُخرج الجميع ويجعل الأسرار المحفوظة غير مقروءة. |
| `BASE_URL` | العنوان العام، مثل `https://kadrix.example.com`. يُستخدم في روابط البريد وعناوين الخطافات وفحص مصدر الطلبات. |

## الخادم

| المتغير | الافتراضي | المعنى |
|---|---|---|
| `PORT` | `3000` | المنفذ |
| `DATA_DIR` | `./data` | مجلد الملفات المرفوعة |
| `WEB_DIST` | لا شيء | مجلد تطبيق الويب المبني، ويقدّمه الخادم عند ضبطه |
| `MIGRATIONS_DIR` | مدمج | مجلد ترحيلات قاعدة البيانات |
| `TRUST_PROXY` | `0` | عدد الخوادم الوكيلة أمام Kadrix. اضبطه على `1` خلف Nginx أو Caddy أو Cloudflare |
| `TRUSTED_ORIGINS` | لا شيء | عناوين إضافية مفصولة بفواصل مسموح لها بإرسال الطلبات غير `BASE_URL`. تلزم خلف الخوادم الوكيلة التي تغيّر ترويسة Origin مثل GitHub Codespaces |

## الأمان والحدود

| المتغير | الافتراضي | المعنى |
|---|---|---|
| `RATE_LIMIT_PER_MINUTE` | `600` | طلبات الواجهة البرمجية في الدقيقة لكل شخص (أو لكل عنوان قبل الدخول). `0` يوقفه |
| `AUTH_ATTEMPTS_PER_5_MIN` | `20` | محاولات الدخول وإنشاء الحساب واستعادة كلمة المرور لكل عنوان. `0` يوقف حدود الدخول |
| `PASSWORD_BREACH_CHECK` | متوقف | `1` يرفض كلمات المرور الجديدة الموجودة في تسريبات معروفة، عبر خدمة Have I Been Pwned بطريقة لا تكشف كلمة المرور: يخرج من الخادم أول 5 أحرف من بصمتها فقط |
| `WEBHOOK_ALLOW_PRIVATE` | متوقف | `1` يسمح للخطافات بالوصول إلى عناوين الشبكة الداخلية |

كلمة المرور من 15 إلى 128 حرفًا وبأي لغة، وتُرفض الشائعة وسهلة التخمين، وفق معيار NIST SP 800-63B-4. أسهل طريقة عبارة طويلة من عدة كلمات لا رابط بينها.

## البريد

| المتغير | المعنى |
|---|---|
| `SMTP_URL` | مثل `smtps://user:password@smtp.example.com:465`. عند ضبطه يصل كل شخص ملخص يومي بالإشعارات غير المقروءة بلغته، ويستطيع إيقافه |
| `MAIL_FROM` | المرسل، مثل `Kadrix <kadrix@example.com>` |

## الذكاء الاصطناعي (متوقف افتراضيًا)

لا يُرسل شيء لأي خدمة ذكاء اصطناعي ما لم تضبط مزودًا. عند التفعيل يظهر زر **تلخيص** في صفحة المهمة وزر **اكتبها عني** عند إنشاء مهمة.

| المتغير | المعنى |
|---|---|
| `AI_PROVIDER` | `openai-compatible` (OpenAI أو نموذج محلي عبر Ollama أو vLLM وغيرها) أو `anthropic` |
| `AI_BASE_URL` | مطلوب مع `openai-compatible`، مثل `http://localhost:11434/v1` لـ Ollama |
| `AI_API_KEY` | مفتاح المزود إن احتاج |
| `AI_MODEL` | اسم النموذج |

## الإصدار

`KADRIX_EDITION` قيمته `self-hosted` افتراضيًا، والقيمة `cloud` محجوزة لخدمة سحابية مستقبلية.
