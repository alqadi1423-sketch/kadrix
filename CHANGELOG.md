## [0.1.0] - 2026-10-16

The first public version, built in internal phases (see
[docs/ROADMAP.md](docs/ROADMAP.md)).

### Added
- Workspaces, projects, issues with keys, workflow states, labels, priorities,
  estimates, sub-issues, relations, comments with mentions, attachments,
  subscriptions and inbox, saved views, bulk edit, list and board, live
  updates, command menu and shortcuts.
- Cycles, burndown and velocity, milestones, initiatives with health
  updates, timeline with critical path, calendar, configurable working week.
- API tokens, OpenAPI, signed webhooks (JSON, Slack, Discord), GitHub and
  GitLab linking, releases and changelogs.
- Docs with live co-editing, guests limited to projects, daily email digest.
- Reports, time tracking, custom fields, templates, recurring issues,
  automation rules, importers (Jira, Linear, GitHub Issues, CSV), Arabic
  search folding.
- AI agents with a built-in MCP server, optional AI provider, typed API
  client, installable app.
- Two-step sign-in, password rules after NIST SP 800-63B-4, optional
  breach check, credential rate limits, trusted proxy setting.
